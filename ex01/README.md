# ex01 · 빈 Eclipse 프로젝트

소스 코드 없이 모듈 선언 파일만 있는 Eclipse Java 프로젝트. 콘솔 예제는 [ex00](../ex00)에 정리.

## 다룬 개념

| 개념 | 뜻과 사용 방법 |
|---|---|
| 모듈 선언 파일 | 프로젝트를 하나의 모듈로 묶고, 외부에 공개할 패키지와 사용할 다른 모듈을 적는 `module-info.java`. 이 폴더의 파일은 이름만 있고 선언 내용 없음 |

## 파일별 내용

| 파일 | 내용 | 핵심 코드 |
|---|---|---|
| [src/module-info.java](src/module-info.java) | 내용이 빈 모듈 선언 | `module ex01 { }` |
